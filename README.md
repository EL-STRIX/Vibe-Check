# GitHub Vibe Check ✨

A cute, Gen-Z style GitHub profile analyzer that reads public activity and serves playful roasts and hypes.

## How to Run Locally

### Option 1 (Zero-dependency - Recommended):
1. In the terminal, run:
   ```bash
   node server.js
   ```
2. Open `http://localhost:3000` in your browser.

### Option 2 (Vercel CLI):
1. In the terminal, run:
   ```bash
   npx vercel dev
   ```
2. Open `http://localhost:3000` in your browser.

> **Note:** VS Code's "Live Server" extension (`127.0.0.1:5500`) only serves static files and cannot execute serverless backend functions (`/api/vibe`). Use `node server.js` or `npx vercel dev` to run the project.
