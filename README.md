# GitHub Vibe Check ✨

A cute, Gen-Z style GitHub profile analyzer that reads public activity and serves playful roasts and hypes.

## How to Run Locally
1. Add your GitHub Personal Access Token (classic, no scopes needed) to `.env.local` or `.env`:
   `GITHUB_TOKEN=ghp_your_token_here`
2. Run with Vercel CLI:
   `npx vercel dev`
3. Open `http://localhost:3000` in your browser.
